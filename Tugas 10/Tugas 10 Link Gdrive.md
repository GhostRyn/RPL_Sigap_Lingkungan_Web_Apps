## Isi Folder Google Drive

Folder Google Drive di atas berisi berkas sumber aplikasi:

- **Source code** — seluruh berkas program web app.
- **Database** — berkas ekspor basis data (misalnya `.sql`) untuk kebutuhan impor ulang.

## Cara Menjalankan di Komputer Lokal

1. Unduh folder dari Google Drive, lalu ekstrak jika berbentuk arsip.
2. Pasang web server lokal, misalnya XAMPP atau Laragon.
3. Salin folder kode ke direktori server (`htdocs` pada XAMPP).
4. Buat database baru melalui phpMyAdmin, lalu impor berkas `.sql` dari folder database.
5. Sesuaikan konfigurasi koneksi database pada berkas konfigurasi aplikasi.
6. Jalankan Apache dan MySQL, lalu buka `http://localhost/nama-folder` di peramban.

> Langkah di atas bersifat umum untuk aplikasi PHP dan MySQL. Sesuaikan jika teknologi yang dipakai berbeda.
